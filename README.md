# প্রথম আলো — খেলাঘর (client preview)

Static preview of the Prothom Alo games hub and the three finished Bangla hero games
(শব্দভেদ, শব্দ সন্ধান, শব্দফুল). Generated by `publish-preview.mjs` in the private build repo —
edit there, not here.

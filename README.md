# প্রথম আলো — খেলাঘর (client preview)

Static preview of the Prothom Alo games hub and the five finished Bangla hero games
(শব্দভেদ, শব্দ সন্ধান, সুডোকু, শব্দফুল, কুইজ). Generated by `publish-preview.mjs` in the private build repo —
edit there, not here.

## How to open it

**Either way works — no build step, no install, no network.**

* **On a web server:** point the document root at THIS folder. Every path
  inside is relative, so it works at a domain root or under a subpath.
* **Straight off a disk:** open `index.html` in a browser. It redirects to
  the hub and everything plays.

Nothing is fetched from the internet at any point: the fonts, icons and every
puzzle are in this folder. It works offline and inside an app webview.

The `*.json.js` / `*.txt.js` files next to each puzzle pack are what make the
second option work — a browser blocks a local page from reading its own data
files, but not from loading a script. Do not delete them.
